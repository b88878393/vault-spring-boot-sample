# Security policy

This repository is a **sample**. It intentionally uses insecure settings for local development (Vault dev mode, a
well-known root token, plain HTTP, demo passwords) that are documented in the README. Those are not vulnerabilities.

If you find a real security problem - for example, the sample code or documentation teaching an unsafe pattern
without saying so, or a secret accidentally committed - please **do not open a public issue**. Report it privately
through [GitHub security advisories](https://github.com/b88878393/vault-spring-boot-sample/security/advisories/new).

You can expect an acknowledgement within a few days. Thank you for helping keep users of this sample safe.
